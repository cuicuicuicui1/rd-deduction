# 研发费用加计扣除辅助软件

面向中小企业的研发费用加计扣除合规辅助工具:立项、费用归集、辅助账、申报汇总、风险自检、备查资料,全流程本地完成。

## 功能

- 企业设置与负面清单行业预警
- 研发项目管理(立项书模板、形式、资本化/费用化)
- 研发人员与工时台账(支持矩阵粘贴与 Excel 导入)
- 费用归集:人员人工、直接投入、折旧、摊销、设计费、其他费用,共用资源按工时/权重分摊
- Excel 批量导入(xlsx/csv,自动匹配列映射;含各类型模板下载)
- 数电票 XML/OFD 批量解析生成费用
- 2021 版研发支出辅助账(97 号公告样式)与 A107012 申报汇总表,可导出 Excel
- 风险自检与备查资料五件套打包

## 政策口径

- 加计扣除比例 100%,资本化按 200% 摊销(财政部 税务总局公告 2023 年第 7 号,长期实施)
- 委托研发境内 80%、境外 80% 且不超过境内符合条件的 2/3(财税〔2018〕64 号)
- 其他相关费用限额按全部项目合并计算(国家税务总局公告 2017 年第 40 号)
- 辅助账样式与备查资料清单按国家税务总局公告 2015 年第 97 号、2021 年第 28 号

## 运行方式

- 打包版(Windows):下载 Release 中的 exe,双击运行,浏览器自动打开 http://127.0.0.1:8765(需本机安装 Edge/Chrome 等浏览器)
- 源码运行:`npm install && npm start`,访问 http://127.0.0.1:8765

数据保存在本机(打包版在 exe 同目录 data 文件夹),不上传任何服务器。

## 开发

- Node.js 后端(express)+ 原生前端(无框架),依赖见 package.json
- 单文件打包:node SEA 方案,见 `scripts/build-exe.ps1`
- core 计算逻辑在 `src/`(风险规则 `src/risk.js`、汇总口径 `src/summary.js` 等)

## 说明

- 本工具依据现行税收法规制作,仅供辅助参考;具体申报口径以主管税务机关意见为准
- 政策条款如有调整,请以最新公告为准
