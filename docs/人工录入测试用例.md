# 人工录入测试用例:验证系统计算正确性

> 用途:**由你人工在系统里录入**,再与本文档「预期结果」逐项对照,验证系统算得对不对。
> 所有预期值都是**独立推算**(非系统输出),推算依据与政策规则已列明,可自行复核。
> 系统当前数据已清空,可直接开录。若已有数据,先在概览页点「清空数据」。

---

## 一、测试设计说明

本用例用 **14 笔费用 + 12 条工时 + 3 人 + 2 项目** 覆盖系统全部关键算法与风险规则:

| 测试点 | 设计 | 触发规则 |
|---|---|---|
| 六大类费用归集 | personnel/direct/depreciation/design/other/entrust 全覆盖 | — |
| 其他费用 10% 限额**超限** | 其他费用 50,000 > 限额 45,555.56 | **R15 红牌** |
| 共用费用按工时分摊 | 折旧 40,000 按工时比 **4:1** 拆到两项目(32,000/8,000) | 辅助账对平 |
| 委托境内 80% | 100,000 → 计 80,000 | — |
| 委托境外 80% + 2/3 限额**超限** | 境外 500,000×80%=400,000 > 境内 535,555.56×2/3=357,037.04 | **R17 黄牌** |
| 费用化/资本化双项目 | P1 费用化 100% 加计;P2 资本化形成无形资产 200,000 | R07 绿牌 |
| 无发票 | 1 笔直接投入不填发票号 | **R11 黄牌** |
| 大额现金 | 1 笔其他费用付款方式=现金(2 万) | **R12 黄牌** |
| 非直接人员 | 丙(会计)不录工时 | 不触发 R08 |
| 节税测算 | 2026 所得 100 万 → 小微 5% | saving=44,629.63 |
| 亏损结转 | 非高企 → 5 年(企业所得税法第十八条) | — |

> 若想看**绿色提示**效果,可加录一笔无凭证号费用(触发 R10)或把甲月工时改为 155/160(触发 R09)。
> 本用例刻意不埋 R10/R09,保持预期结果简洁(红1/黄3/绿1)。

## 六、本用例的推算口径备注(便于复核)

- 其他费用限额按**全部项目合并**计算(2017 年 40 号):前 5 类 410,000 × 10% ÷ 90%。
- 委托境外计入 = min(境外×80%, 境内合计×2/3);境内合计 = 前5类 410,000 + 其他可扣 45,555.56 + 委托境内×80% 80,000 = 535,555.56;×2/3 = 357,037.04。
- 加计基数中其他费用按**限额内**金额 45,555.56 计入(超限部分先剔除)。
- 节税 = 加计额 × 适用税率;2026 应纳税所得额 100 万 ≤ 300 万 → 小微 5%(若利润为负则显示"新增亏损+结转年限")。
- 非高企亏损结转 5 年;高企/科技型中小企业 10 年(财税〔2018〕76 号)——系统按企业档案 isHiTech 自动区分。
