## 场景 1:中型制造业(费用化+资本化+委托境内+共用设备工时分摊)

**恒力智能装备制造有限公司**,查账征收,非高企。2 个项目:

| 项目 | 政策 | 费用 |
|---|---|---|
| RD-01 智能装配线研发 | 费用化 | 人员 800,000 / 直接投入 300,000 / **共用折旧 120,000(按工时)** / 摊销 60,000 / 设计 90,000 / 其他 150,000 / 委托境内 400,000 |
| RD-02 精密减速机试制 | 资本化(未结题) | 人员 500,000(资) / 直接投入 350,000(资) |

工时:RD-01 160h : RD-02 40h = 4:1

### 手工推导

1. 共用折旧 120,000 按 4:1 → RD-01 分 96,000、RD-02 分 24,000
   **关键口径**:分摊额按**目标项目**资本化属性定型 —— 分到费用化项目 → 费用化;分到资本化项目 → 资本化(构成无形资产成本)
2. 费用化前5类 base5 = 人员 800,000 + 直接 300,000 + 折旧 96,000 + 摊销 60,000 + 设计 90,000 = **1,346,000**
3. RD-02 无摊销记录 → 未形成无形资产 → 不计入限额基数
4. 其他费用限额 = 1,346,000 ÷ 9 = **149,555.56**;其他费用 150,000 → **超限 444.44**
5. 委托境内 400,000 × 80% = 320,000
6. **加计基数 = 1,346,000 + 149,555.56 + 320,000 = 1,815,555.56**
7. 资本化形成成本 = 500,000 + 350,000 + 24,000(分摊) = **874,000**
8. 节税(所得额 300 万,小微 5%)= 1,815,555.56 × 5% = **90,777.78**

### 对照结果:17 项全过 ✅

会计口径 2,770,000 ✓;base5 1,346,000 ✓;限额 149,555.56 ✓;加计基数 1,815,555.56 ✓;资本化 874,000 ✓;辅助账 P1 1,896,000 / P2 874,000 ✓;行40=行47=1,815,555.56 ✓;高企口径 2,690,000 ✓;节税 90,777.78 ✓

## 场景 2:软件企业(高新技术企业 + 委托境外未超限 + 其他费用超限)

**云启软件技术有限公司**,高企,查账征收。自研费用化 1 项目:

人员 1,200,000 / 直接投入 180,000 / 折旧 150,000 / 其他 200,000 / 委托境外 900,000 / 委托境内 300,000

### 手工推导

1. base5 = 1,200,000 + 180,000 + 150,000 = **1,530,000**
2. 其他费用限额 = 1,530,000 ÷ 9 = **170,000**;其他费用 200,000 → **超限 30,000**
3. 委托境内 300,000 × 80% = 240,000;委托境外 900,000 × 80% = 720,000
4. 境内基数 = 1,530,000 + 170,000 + 240,000 = **1,940,000**;2/3 限额 = **1,293,333.33**
5. 720,000 < 1,293,333.33 → 境外全额
6. **加计基数 = 1,530,000 + 170,000 + 240,000 + 720,000 = 2,660,000**
7. 节税(高企,所得额 800 万 → 15%)= 2,660,000 × 15% = **399,000**;亏损结转 10 年

### 对照结果:15 项全过 ✅

会计口径 2,930,000 ✓;限额 170,000 ✓;剔除 30,000 ✓;境外 2/3 限额 1,293,333.33 ✓;加计基数 2,660,000 ✓;高企口径 2,690,000 ✓;税率 15% ✓;节税 399,000 ✓
