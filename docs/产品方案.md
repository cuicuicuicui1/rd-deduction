# 研发费用加计扣除合规管理系统 —— 产品与技术方案

> 版本: v0.1(方案稿)  编制: 2026  |  定位: 中小企业研发费用加计扣除"立项—归集—出账—自检—申报"全流程合规工具

---

## 一、背景与痛点分析

### 1.1 政策背景:优惠力度加大、监管同步趋严

- 研发费用加计扣除比例已提高至 **100%**(费用化部分据实扣除后再加计 100%;形成无形资产的按成本的 **200%** 摊销),自 **2023 年 1 月 1 日起作为制度性安排长期实施(财政部 税务总局公告 2023 年第 7 号)**。
- 加计扣除形成的亏损,结转年限由 5 年延长至 **10 年**(2023 年第 7 号公告)。
- 享受方式为"**自行判别、申报享受、相关资料留存备查**",企业是合规第一责任人。
- 金税四期/以数治税下,税务系统通过**预警指标体系**自动扫描申报数据,异常即触发纳税评估、案头分析乃至稽查。

### 1.2 中小企业六大不规范表现(经不起查的根源)

| # | 环节 | 典型问题 | 稽查后果 |
|---|------|----------|----------|
| 1 | 立项 | 无立项计划书、无立项决议、事后补立项、立项时间晚于费用发生时间 | 研发真实性存疑,全额剔除 |
| 2 | 人员人工 | 研发人员名单与劳动合同/个税申报不一致、无工时记录、行政/生产人员混入 | 剔除相关人员费用 |
| 3 | 直接投入 | 领料单无"研发专用"标识、与生产领用混同、未按项目归集 | 剔除无法证明用于研发的材料 |
| 4 | 折旧/摊销 | 共用设备、软件未做使用量/工时分摊,或分摊无依据 | 剔除全额列支部分 |
| 5 | 委托研发 | 未按实际发生额 80% 计算、无合同/发票、境外委托超境内 2/3 未剔除、关联方无费用明细 | 多扣部分补税 |
| 6 | 其他费用 | 超 10% 限额未扣减、把咨询/招待等费用塞入、与"高新认定口径"混用 | 调增+滞纳金+罚款(0.5~5 倍) |

### 1.3 根因

1. **缺工具**:财务仍用 Excel 手工归集,口径靠人肉记忆;
2. **缺模板**:立项书、工时表、费用分配说明没有标准化模板;
3. **缺过程留痕**:研发过程"三无"(无决议、无工时、无领料标识),事后无法补证;
4. **缺复核**:无人对照政策逐条自检,临近申报期才匆忙凑数;
5. **口径不清**:会计账、加计扣除口径、高新认定口径"三本账"不一致。

## 二、政策依据速览(系统内嵌规则库)

| 政策文件 | 关键内容 |
|----------|----------|
| 财税〔2015〕119 号 | 加计扣除制度框架;负面清单行业;不适用研发活动(7 类);六大类费用范围 |
| 国家税务总局公告 2015 年第 97 号 | 归集口径细化;委托/合作/集中研发处理;辅助账要求;备查资料清单 |
| 国家税务总局公告 2017 年第 40 号 | 执行口径:其他相关费用限额按**全部项目合并计算**;人员/折旧/分摊口径 |
| 财税〔2018〕64 号 | 委托境外研发:按实际发生额 80% 计入,且不超过境内符合条件的研发费用 **2/3** |
| 国家税务总局公告 2021 年第 28 号 | 发布 **2021 年版研发支出辅助账样式**(简化版);预缴申报期可享上半年优惠 |
| 财政部 税务总局公告 2023 年第 7 号 | 加计比例统一 **100%**、摊销 **200%**,长期实施;亏损结转 **10 年** |

### 2.1 关键参数(系统硬编码并展示依据)

- 加计比例:费用化 **100%**;资本化摊销 **200%**
- 负面清单行业:烟草制造业、住宿和餐饮业、批发和零售业、房地产业、租赁和商务服务业、娱乐业
- 不适用研发活动:常规升级、直接应用、技术支持、重复/简单改变、市场调研/管理研究、常规质控检测维修、社科艺术人文研究
- 委托研发:境内(机构/个人)按实际发生额 **80%**;境外按 **80%** 且不超过境内符合条件研发费用的 **2/3**
- 其他相关费用限额 = 前五类费用合计 × **10% ÷ 90%**(全部项目合并计算,40 号公告)
- 备查资料(留存 10 年):立项计划书+决议文件、研发机构编制及人员名单、费用分配说明(含工时记录)、集中研发分摊资料、**研发支出辅助账及汇总表**、鉴定意见(如有)、委托合同/发票/付款凭证、技术合同登记(境外委托)

### 2.2 辅助账(2021 年版样式核心要素)

按项目设账,记录:日期、凭证号、摘要、费用类别(人员人工/直接投入/折旧/无形资产摊销/新产品设计费等/其他相关费用)、支出类型(费用化/资本化)、金额;期末分项目、分类别汇总,并生成《研发费用加计扣除优惠明细表》(A107012) 填报数据。

## 三、产品方案

### 3.1 价值主张

> **"从立项到申报,全过程留痕、自动出账、风险自检、备查无忧"** —— 让企业把"经不起查"变成"随时经得起查"。

### 3.2 目标用户

1. 有研发投入的中小企业(制造/软件/生物医药等)财务与研发部门;
2. 代理记账机构、税务师事务所(多客户多账套服务);
3. 高新培育/认定辅导机构(双口径对照)。

### 3.3 功能架构(八大模块)

```
┌─────────────────────────────────────────────────────────┐
│  ① 基础设置:企业信息/行业(负面清单自动预警)/会计政策/期间  │
│  ② 研发项目管理:立项(模板+决议)→过程→结题,形式与状态管理    │
│  ③ 人员与工时:研发人员名册、月度工时台账(研发/非研发分摊)   │
│  ④ 费用归集:六大类+委托,直接归集/按工时/按使用量分摊       │
│  ⑤ 辅助账引擎:按 2021 版样式自动生成,分项目/分类别/分期间   │
│  ⑥ 申报汇总:自动计算 10% 限额、委托 80%、境外 2/3,生成     │
│     A107012 参考数据 + Excel 导出                          │
│  ⑦ 风险自检引擎:20+ 条预警规则 → 红/黄/绿风险报告          │
│  ⑧ 备查资料管理:留存清单 + 扫描件归档 + 到期提醒            │
└─────────────────────────────────────────────────────────┘
```

### 3.4 核心业务流程(全流程闭环)

```
立项(模板/决议/计划书)
   ↓
人员名册+月度工时台账 ──┐
费用凭证录入(六大类) ──┼─→ 分摊引擎 ─→ 研发支出辅助账(2021版)
共用设备/材料分摊 ─────┘         ↓
                       合规自检(预警规则) ─→ 风险报告/整改
                              ↓
                       A107012 申报参考 + 备查资料清单归档
```

### 3.5 关键设计:三口径对照

同一费用明细支持打标签:`会计口径` / `加计扣除口径` / `高新认定口径`,系统输出差异对照表(高新认定研发费用占比 5%/4%/3% 门槛、其他费用 10% vs 20% 限额差异、人员口径差异等),防止"一套数三处用"被比对出不一致。

### 3.6 风险自检引擎(规则库示例,系统内 20+ 条)

| 级别 | 规则示例 |
|------|----------|
| 红(阻断) | 负面清单行业享受加计;核定征收企业享受;其他相关费用超 10% 限额未扣减 |
| 黄(预警) | 无立项决议/计划书;无工时记录;研发人员工时占比异常;共用费用无分摊依据;委托境外超境内 2/3;立项时间晚于费用发生时间;费用无凭证号;现金大额支付;费用跨项目期间 |
| 绿(提示) | 研发费用占营收比例偏离行业均值;研发费用较上年激增;亏损企业大额加计(提示 10 年结转);资本化项目无摊销说明;与高新申报数据一致性提示 |

## 四、技术方案

### 4.1 总体架构

```
┌──────────────────────────── 本地单机部署(数据不出企业) ───────────────────────────┐
│  Browser(单页应用,无需构建)                                                      │
│      │ REST API (JSON)                                                          │
│  Node.js 服务层:路由 / 领域引擎(归集·分摊·限额·辅助账·自检) / 导出                 │
│      │                                                                            │
│  存储层:JSON 文件持久化(当前 MVP)→ 可平滑替换 SQLite/PostgreSQL(SaaS 化时)          │
└───────────────────────────────────────────────────────────────────────────────────┘
```

- **数据安全优先**:财务数据敏感,MVP 定位本地运行、数据不出企业;后期 SaaS 采用多租户隔离 + 字段级加密 + 等保要求;
- **架构可演进**:领域引擎与存储层解耦,未来可无缝切换数据库、增加 OCR 发票识别、对接电子税务局申报接口。

### 4.2 核心数据模型

```
Company(企业):名称/信用代码/行业(负面清单判定)/征收方式/是否高新/人数/收入·资产
Project(项目):名称/编号/起止期/研发形式(自主·委托境内·委托境外·合作·集中)/状态/资本化策略
Staff(人员):姓名/岗位/是否直接研发/入职时间
Timesheet(工时):人员×项目×月份 → 研发工时/总工时(分摊依据)
Expense(费用):项目×类别(六大类+委托)×期间/凭证/金额/分摊方法(直接·工时·使用量)
Amortization(摊销):资本化项目年度摊销额(200% 加计)
```

### 4.3 技术栈

| 层 | 选型 | 理由 |
|----|------|------|
| 后端 | Node.js + Express | 环境轻、纯 JS 生态、无原生编译依赖 |
| 存储 | JSON 文件(可升级 SQLite) | MVP 零依赖、可读可备份、易迁移 |
| 导出 | exceljs(纯 JS) | 生成带样式的 .xlsx,适配 2021 版辅助账样式 |
| 前端 | 原生 HTML/CSS/JS 单页 | 无构建、离线可用、内网可部署 |
| 部署 | `npm start` 单进程 | Windows/macOS/Linux 通用;可选打包成桌面应用 |

### 4.4 实施路线

| 阶段 | 内容 | 周期 |
|------|------|------|
| **MVP(本次交付)** | 企业/项目/人员工时/费用归集 + 分摊 + 2021 版辅助账 + A107012 汇总 + 10%/80%/2/3 限额引擎 + 20+ 条风险自检 + Excel 导出 + 备查清单 | 1~2 周 |
| V1.1 | CSV/Excel 批量导入、发票 OCR、三口径对照台账、高新认定报告 | +2~4 周 |
| V1.2 | 多账套/多客户、用户权限、审计留痕(谁在何时改了账)、政策库动态更新 | +4 周 |
| V2 | SaaS 多租户、电子税务局申报对接、行业预警指标库实时更新、智能稽核预演 | 规划中 |

### 4.5 合规与责任边界

1. 软件输出为**申报辅助与合规自检**,不构成税务专业意见;重大事项建议经税务师/会计师复核;
2. 政策库版本化维护,政策更新时软件内提示;
3. 所有"自动计算"均展示**计算公式与政策依据**,可追溯。

## 五、MVP 交付说明

本方案已同步落地可运行 MVP(见 `rd-deduction/` 目录):

- `npm start` 启动,浏览器访问 `http://127.0.0.1:8765`;
- 内置示例数据一键载入,可直接看到:辅助账、A107012 汇总(含限额计算明细)、风险自检报告;
- 覆盖:企业设置、项目管理、人员与工时、费用归集、辅助账、申报汇总、风险自检、备查清单八大页面。
