## 四、主动审查发现（教科书算法对账之外）

### 发现 1【中风险】工时缺失时共享费用静默回退，风险引擎存在盲区
- **现象**：`allocMethod=ratioHours` 的共享费用，在目标期间工时台账为空时，计算端**无提示地全额回退**到挂靠项目（案例 H 实测：删除工时后行51 从 850,000 悄变为 1,250,000，项目间分布从 60/40 变 100/0）。
- **影响**：加计总额不变，但**项目间归集失真 + 分摊依据缺失**——119 号/40 号公告要求共用费用留分配记录，稽查核查点之一。
- **盲区确认**：R08 仅覆盖 staff 名单人员、R14 仅覆盖"未选分摊方法"、R41 仅覆盖折旧/摊销/其他类共用，均不检查"ratioHours 费用的目标期间是否有工时数据"。删工时后风险清单无任何相关预警。
- **建议**：增加规则"按工时分摊的费用，其期间无任何工时记录 → 黄色预警"。

### 发现 2【中风险】amortizations/specialIncomes 无项目存在性校验，幽灵摊销虚增行43
- **现象**：向不存在的 projectId 录入摊销 77,777 → 顺利入库且**计入 A107012 行43**（实测 200,000 → 277,777）。specialIncomes 同样不校验（首轮案例 B 曾带垃圾 projectId 入库）。
- **对比**：expenses 端有双重防线（录入时"项目不存在"校验 + 计算端 P0-3 孤儿剔除），amortizations 两道均缺，防护不对称。
- **影响**：项目删除后残留摊销记录、API 误录 → **虚增本年摊销加计扣除额且无任何提示**。
- **建议**：amortizations/specialIncomes 录入校验项目存在；计算端对 amortAmount 增加孤儿过滤（与 expenses P0-3 对齐）。

### 发现 3【低风险】不征税收入剔除被机械呈现为"资本化金额"虚增
- **现象**：案例 F 中行42"本年资本化金额(40−41)"显示 100,000——实为不征税收入剔除额，并非真实资本化支出。官方表内公式即 40−41，但系统未加注说明，用户易误读。
- **建议**：行42 note 中注明"含不征税收入对应支出剔除 X 元"。

### 通过项（抽查无异常）
- 录入口径：负金额 / NaN 字符串 / "NaN"字符串均拒绝；摘要关键词拦截正确（"水电"挂 other 拦截、挂 direct 作为研发动力费放行——符合 119 号/40 号口径）；重复提交幂等去重（返回同 id + deduplicated 标记）。
- 工时校验：rdHours > totalHours 正确拒绝（案例 H 首轮误录被拦截）。
- 导出接口：A107012/辅助账/汇总/97号/备查包 zip/风险报告 HTML 共 7 项全部 HTTP 200 且文件头合法（xlsx/zip 均为 PK 容器）。
- 数据安全：demo/clear 每次自动 preclear 备份（实测存在）；审计后用户数据恢复完整。
- 口径一致性：全部案例中 A107012 行51 与参考口径行14 恒等；ledger97 domesticBase 与行2+行36×80% 恒等；特殊收入冲减在两口径下总额一致。
